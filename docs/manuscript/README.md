3. [`instructor_guide_solutions.md`](instructor_guide_solutions.md) - Supporting Information 2: Comprehensive Instructor Guide & Full Solution Key with Grading Rubric.
4. [`joss_paper.md`](joss_paper.md) - Backup manuscript formatted according to JOSS (`paper.md`) submission guidelines.
